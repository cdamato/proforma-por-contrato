# Proforma por contrato

Prototipo interactivo de la Proforma del proveedor agrupada por contrato (Control de costes · 011h).

- Diseño en Figma: https://www.figma.com/design/xgqGVHd2g7hCtrHjnp7Bci/MASTER---PROCUREMENT?node-id=739-33595
- Un solo archivo estático (`index.html`), sin build.

Qué se puede probar: desplegar contratos, filtrar por contrato, asignar contrato y centro de coste a las líneas fuera de contrato, seleccionar y eliminar líneas, descargar (PDF o ZIP) y liquidar el proveedor. Los totales se recalculan a partir de las filas.

Datos de ejemplo: el nombre del proveedor está anonimizado.
